## Lab Directory

### [Lab 01: Web Foundations & Bootstrap](./Lab-01)
Covers HTML5 semantics, custom CSS styling, and responsive UI design using Bootstrap 5.
- `bootstrap-demo.html` — Responsive developer portfolio built with Bootstrap 5 components, grid system, and custom styling.
- `style.css` — Custom dark-theme styles, typography, and hover animations.
- `index.html` — Webpage demonstrating semantic HTML tags.
- `assets/` — Media assets used across the lab pages.

### [Lab 02: Advanced CSS, Flexbox & Responsive Portfolio](./Lab-02)
Focuses on advanced CSS3 layouts, CSS Flexbox architecture, CSS positioning, pseudo-elements, interactive transitions/transforms, CSS image filters, and Bootstrap Flex utilities.
- `index.html` — Complete responsive single-page student portfolio integrating all 5 practical lab tasks.
- `style.css` — Modular design system, Flexbox grids, image filters, transitions, pseudo-element accents, and media queries.
- `assets/` — Profile photo and custom SVG project illustrations for Web, Database, and AI/ML case studies.
